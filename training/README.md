# PhotoHDR MV — Phase 3 Fine-Tune Scaffold

Training scripts for the three fine-tuneable models in the v3 spec:

| Script | Model | Purpose | Min dataset |
|---|---|---|---|
| `train_nafnet.py` | NAFNet | Final style + quality polish (replaces Real-ESRGAN final step) | 20,000 before/after pairs |
| `train_segformer.py` | SegFormer (b0) | Window-mask segmentation (replaces Grounded SAM when it underperforms) | 1,000 annotated interior window masks |
| `train_lightfuse.py` | LightFuse | Learned exposure fusion (replaces Enfuse when quality is insufficient) | 500+ bracket sets with paired finals |

**Cannot run yet.** Training data is generated by Phase 1+2 producing finished output at scale. Per v3 Section F: "Bootstrap Phase 3 training data: Run your own shoots through the Phase 2 pipeline to generate polished before/after pairs."

Order of operations:
1. Alan finishes Phase 0b benchmark (need brackets on dev box).
2. Phase 1 worker runs against ~50 properties in production to validate fusion quality.
3. Phase 2 generative ops run on those outputs to produce final polished images.
4. **Now** there are pairs (raw → Phase 2 output) — use them as NAFNet training inputs.
5. After ~6 months of normal shoots, dataset hits 20k+ pairs; NAFNet fine-tune becomes viable.

Window-mask SegFormer fine-tune can start earlier — only needs 1,000 manually-annotated masks. The annotation work could run in parallel to Phase 1.

## Hardware

Target dev box: Windows + RTX 5070 Ti (16GB VRAM, CUDA 12.8, Blackwell sm_120).

Constraints per v3 Section F3:
- 256×256 patch training, batch size 16 (full-res 24MP won't fit)
- LoRA-style fine-tuning preferred
- Small segmentation model fine-tuning (SegFormer-b0 fits; b2 won't)
- **Not** full-resolution end-to-end training — use RunPod for that

## Usage (when data exists)

```bash
cd training
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# NAFNet
python train_nafnet.py --data ../dataset/training_pairs/ --output runs/nafnet_v1 --epochs 200

# SegFormer (window masks)
python train_segformer.py --images ../dataset/window_masks/ --output runs/segformer_b0_v1 --epochs 80

# LightFuse (exposure fusion) — needs bracket sets + reference fused outputs
python train_lightfuse.py --brackets ../dataset/ --references ../dataset/finals/ --output runs/lightfuse_v1 --epochs 100
```

## Data preparation

### NAFNet (before/after polish)

Expected layout:
```
dataset/training_pairs/
  pair_000001/
    before.jpg   ← Phase 1 fusion output
    after.jpg    ← Phase 2 generative output (or Alan's Lightroom final)
  pair_000002/
    ...
```

Pairs must be the same dimensions. Bootstrap script: TODO — extract from photo-editor DB once Phase 2 has produced ≥1k completed projects.

### SegFormer (window masks)

```
dataset/window_masks/
  property_0001_room_001/
    image.jpg
    mask.png    ← white = window, black = not window
  ...
```

Annotation: use Label Studio (free, self-hosted) or CVAT. Allocate ~30 seconds per image for an experienced annotator → 1,000 masks = ~8 hours.

### LightFuse (exposure fusion)

```
dataset/lightfuse_pairs/
  pair_000001/
    bracket_-2.jpg
    bracket_0.jpg
    bracket_+2.jpg
    fused.jpg    ← Alan's Lightroom HDR Merge or AutoHDR output as ground truth
  ...
```

## Why not just use the off-the-shelf models forever?

- NAFNet fine-tune embeds Alan's specific look (cool-warm balance, contrast curve, sharpness preference). Cheaper than per-image API calls at scale.
- SegFormer fine-tune handles MV's specific window styles (small panes, French doors, beach-house bays) that the off-the-shelf Grounded SAM misses.
- LightFuse only matters if Enfuse fusion quality fails on Alan's shoots — verify in Phase 0b benchmark first.

## What this scaffold does NOT do

- Doesn't bootstrap training data — that's a separate script that hasn't been written because Phase 1+2 hasn't run on real shoots yet.
- Doesn't push trained weights anywhere. After training, copy `runs/<model>/best.pt` somewhere durable manually.
- Doesn't include LoRA conversion — add when needed.
